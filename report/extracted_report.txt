1.2 (b) A scalar nonlinear encoding
Set B = K + 1, ϕ(−1) = 1, ϕ(0) = B, ϕ(+1) = B2. If counts are (a, b, c), the aggregate is
m = a + Bb + B2c. Each count is at most K < B, so no carries occur. Decode by a = m mod B,
replace m by ⌊m/B⌋, recover b = m mod B, divide again, and obtain c. This is unique base-B
representation; it relies on exact arithmetic (large K may require integers beyond floating-point
precision). For counting only non-steady neighbours, ϕ(x) = x2 = |x| on this alphabet gives
a + c directly. For K=8, the NumPy script checks all 164 triples with total size 1 through 8
(binomial(11,3)-1 = 164). Every code is unique and every decoded triple equals its input. The
exact stdout and structured outputs are in logs/q1_q2.log and results/q1_q2.json.

were checked against every multiset of size 1–8; exact rational keys avoid floating-point collisions

2.1 (a) Symmetric spatial layer
For the isolated spike, predictions at sensors (19, 20, 21) are (b, a, b) and targets are (1, 0, 0). All
other errors vanish, hence
L(a, b) = (b − 1)2 + a2 + b2, ∂aL = 2a = 0, ∂bL = 4b − 2 = 0.
Thus a = 0, b = 1/2, uniquely, since the Hessian is diag(2, 4) and positive definite. The fitted
readings are (1/2, 0, 1/2) versus (1, 0, 0), giving minimum squared error 1/2. NumPy least squares
confirms these coeﬀicients. The fitted layer averages its two neighbours, producing symmetric dif-

2.2 (b) Directional neighbours
Choose a = 0, w− = 0, w+ = 1. Substitution gives ˆxi(t + 1) = xi+1(t) identically for every
snapshot. The cross-correlation kernel multiplying [xi−1, xi, xi+1] is [0, 0, 1]; use circular padding
of one sample on either side (a mathematical convolution convention reverses the stored kernel).
Direction labels distinguish the ahead and behind neighbours, breaking the reflection ambiguity.
Identical symmetric layers and pointwise nonlinearities alone preserve the isolated spike’s reflection
symmetry at sensors 19 and 21.
2.3 (c) History with equal spatial weights
Under backward motion, xi−1(t) = xi(t − 1). Therefore
ˆxi(t + 1) = axi(t) + (b + c)xi−1(t) + bxi+1(t).
For equality to xi+1(t) for every snapshot, equate coeﬀicients: a = 0, b = 1, c = −1. The two
spatial neighbours sum, and history subtracts the neighbour from which the current reading has
already moved. For forward motion xi(t) = xi−1(t − 1), so xi(t − 1) = xi+1(t) and the same
coeﬀicients yield
ˆxi(t + 1) = xi−1(t) + xi+1(t) − xi+1(t) = xi−1(t).
The same coeﬀicients therefore also work for forward motion; they do not fail for a consistent
forward history. History breaks the snapshot reflection ambiguity by exposing the direction of

value. Constant or otherwise indistinguishable patterns can remain direction-ambiguous, but the

3.1 (a) Extraction, units and missingness
The Kaggle CLI first listed all seven files. Only ca_his_raw_2020.h5, ca_his_raw_2021.h5,
ca_meta.csv and ca_rn_adj.npy were downloaded. The oﬀicial San Diego notebook filters District
== 11; here all 716 selected entries also have County == San Diego. Metadata ID strings select
HDF columns, while the same rows’ ID2 values select both axes of the full graph. Assertions verify
unique IDs, 716 sensors, column order and the ID2-to-ID mapping. The graph order convention
comes from the oﬀicial notebook; no raw graph ID labels are supplied independently.
PeMS Total Flow is the vehicle count across lanes during a five-minute interval, normalized
upstream for good controller samples [3]. We therefore sum three counts, yielding vehicles per 15
minutes. The LargeST repository’s CA preprocessing instead averages three values and rounds, re-
taining a five-minute-equivalent average volume [2]. Our sum preserves interval volume and follows
the assignment’s explicit interval-count instruction; metric magnitudes should not be compared
directly with publications using the repository’s averaging convention.
There are 7,636,666 nonfinite/missing raw SD readings out of the two-year complete grid
(5.066183%). Zeros are retained as valid readings, not reclassified as missing. Each year is rein-
dexed to a complete five-minute grid, separately split at the prescribed boundaries, then causally
forward-filled inside that split. Leading gaps in training use zero; leading gaps in validation/test
use each sensor’s training-only mean after training imputation. No validation/test reading con-
tributes to those fallback means or normalization. No backward fill or cross-boundary fill is used.
Filling precedes summation so missing subintervals cannot silently shrink a quarter-hour count.
Long outages can yield stale artificial plateaus; evaluation includes imputed targets and may un-
derstate error on genuinely observed traﬀic. PeMS may already impute upstream, and these files
do not expose observation flags.

4 Q4 – Forecasting architecture and protocol
4.1 (a) Windows and leakage controls
Every window has input shape (8,716,1) and target shape (4,716,1). Train uses all of 2020, valida-
tion January–March 2021, and test April–December 2021. Windows are constructed independently
inside each array, with len(split)-11 samples; the first input starts at the split boundary and pre-
dicts steps 8–11. No input or target crosses a split. Training-only global mean is 584.440713411
and population standard deviation is 488.149905535 vehicles per 15 minutes. Both inputs and
targets use these statistics. Graph embeddings learn only through training losses; validation se-
lects the checkpoint, and the untouched common test period is used only for final evaluation and
descriptive plots/analysis.
4.2 (b) Architecture and training
The shared temporal encoder applies two Conv1d layers per sensor: channels 1→16→16, kernel
size 3, padding 1, ReLU after each. It retains the last temporal position, giving Z of shape
7
(batch,716,16). All inputs are historical, so symmetric convolution padding within the eight-step
history does not expose targets. The graph variants compute H = ReLU(A Z Wg), with one
bias-free 16×16 graph projection. A shared linear 16→4 head predicts four direct horizons. Every
model adds the last normalized local reading to all four outputs as an identical persistence residual.
Temporal-only feeds Z directly to the same head; the three STGNNs differ only in adjacency.
Negative forecasts are not clipped.
All runs use CPU, seed 42 for Python/NumPy/PyTorch, Adam lr 0.001, batch size 64, shuf-
fled full training windows, normalized MAE loss, patience 5 on full validation MAE, and the
lowest-validation checkpoint. Hidden dimension 16 is within the assignment’s 16–32 CPU guid-
ance. PyTorch deterministic algorithms are enabled, with no GPU operations or extra DataLoader
workers. Each model has a fresh optimizer and a reset seed; shared encoder/head initialization
matches. There is one graph layer, no dropout, and no weight decay. A complete one-epoch trial
for each model precedes fresh final fits; trials are discarded and do not initialize final fits. The
measured trials determine a common maximum of 30 epochs, capped at 30, reserving time inside a
7,200-second training budget. Per-epoch normalized train/validation MAE and times are recorded
in JSON and logs.

5 Q5 – Fixed, adaptive and hybrid graphs
5.1 (a) Fixed
Because A is asymmetric we use ˆAij = (A + I)ij / ∑ k(A + I)ik rather than symmetric degree
normalization. The original diagonal is retained and I is added as specified, increasing self mass.
All row sums equal one, including isolated nodes after adding identity. This tensor is a frozen
buffer, not a trainable parameter. Nonzero ˆAij weights the feature of source j in the update of
receiver i.

6.3 (c) Critical discussion
Lower forecast error does not establish actual road connectivity: optimizing prediction can exploit
shared schedules or missing-data artifacts, and the measured standalone top-10 road overlap is
only 3.561%. Forecasting and physical graph recovery are different targets; no connectivity labels
supervise the embeddings.
A hybrid may outperform either source by retaining local physical propagation while learning
complementary global demand signals, with alpha regulating that tradeoff. Here alpha = 0.002558;
its test MAE is 59.946 against fixed 69.308 and adaptive 59.392. The observed comparison, includ-
ing any lack of improvement, is reported without claiming that mixing guarantees a gain.
Here the learned fixed-graph mixing mass is only 0.255803%, so the selected hybrid is effectively
adaptive. Its MAE exceeds standalone adaptive by 0.554; this run does not show a gain from
combining the two sources.
A static graph averages morning/evening direction changes, weekday versus weekend demand,
incidents, closures and evolving queues. A single scalar alpha cannot express such variation, and
road-distance edges do not encode travel-time delays. A future time-conditioned graph could
address this, but it would require leakage-safe training, stronger regularization and additional
compute. The 2020-to-2021 split also faces pandemic-era demand shift; imputed targets and a
single seed limit external validity.
